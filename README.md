# RReklam

Платформа автомобильной рекламы для Армении. Частные водители, такси и автопарки; агентство — посредник. Армянский язык по умолчанию, русский и английский дополнительно.

**Статус: MVP в разработке, не готов к публичному запуску.** [Что реализовано](docs/IMPLEMENTATION_STATUS.md) · [Наши решения](docs/DECISIONS.md).

## Первый локальный запуск

Нужно: Node.js 22+, npm и Docker с Compose. Данные в `docker-compose.yml` — только для локальной разработки; не публикуйте их в интернете.

```bash
git clone https://github.com/Rob1-997/rreklam.git
cd rreklam
npm install
cp .env.example .env
docker compose up -d
npm run db:generate
npm run db:migrate -- --name init
npm run db:seed
npx prisma db execute --file prisma/sql/booking_constraints.sql --schema prisma/schema.prisma
npm run dev
```

Открыть http://localhost:3000, маршруты /hy, /ru, /en. На сайте работает предпросмотр заявки. Авторизованные пользователи с подтверждённым телефоном могут отправить предварительный запрос на несколько городов; менеджер увидит его в своей очереди. **Это не подтверждённый заказ, не бронирование и не оплата.**

В Windows вместо `cp` используйте `copy .env.example .env`.

### Настройка авторизации

В `.env` необходимо задать реальные, **секретные** значения (никогда не отправлять их в чат и не коммитить в GitHub):
- `AUTH_SECRET` — криптографически случайная строка (например, `openssl rand -base64 32`).
- `OTP_PEPPER` — независимый случайный секрет длиной от 32 символов.
- `AUTH_GOOGLE_ID` / `AUTH_GOOGLE_SECRET` — OAuth Google.
- `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM` — провайдер SMS; перед запуском проверить поддержку доставки в Армению, цены и нормативные требования.
- `DATABASE_URL` — PostgreSQL, `S3_*` — приватное хранилище фотографий. Compose поднимает локальный MinIO с тестовыми настройками.
Без подключённых Google/SMS авторизация не будет работать, а без S3 — нельзя отправить четыре фотографии.

Аккаунт, вошедший через Google, должен подтвердить телефон; после этого может подать заявку водителя. Активация роли PERFORMER выполняется менеджером или владельцем через защищённый API.

### Первоначальный владелец

Зарегистрируйте через Google пользователя с Email, подтвердите телефон. Только затем локально задайте `BOOTSTRAP_OWNER_EMAIL` в `.env`, а `BOOTSTRAP_CONFIRM=GRANT_INITIAL_OWNER`. Один раз выполните:

```bash
npx tsx scripts/bootstrap-owner.ts
```

Сразу удалите временную переменную подтверждения из `.env`. Bootstrap блокируется, если активный владелец уже существует. **Не запускать на неподготовленной production-базе.**

## Кабинеты и API

- `/hy/driver` — водитель: заявка, машины, четыре фото, статусы модерации.
- `/hy/admin` — OWNER/MANAGER: очередь заявок, решение с проверкой прав собственника, запас машин и проверка доступности на будущие даты.
- `/api/locations`, `/api/body-types` — справочники для разработки.
- `/api/driver/profile`, `/api/vehicles` — защищённая регистрация.
- `/api/client/campaigns` — подача предварительного запроса с несколькими городами после входа и подтверждения телефона; утверждение стоимости и оплата не подключены.
- `/api/admin/campaigns` — только заявки клиентов назначенного менеджера (владелец видит все).
- `/api/admin/vehicles`, `/api/admin/drivers`, `/api/admin/stock`, `/api/admin/availability` — только для активированных сотрудников.

Не загружать реальные документы водителей в тестовую среду. Отдельно согласовать публикацию условий, политик хранения данных и юридических согласий.

## Финансовые правила

- Все суммы в AMD; владелец утверждает базовые тарифы и изменения.
- Любая скидка требует утверждения владельцем.
- Минимальная маржинальность 25%, исключения утверждает владелец с причиной.
- Клиент оплачивает 100% заранее; платежи ещё не подключены.
- Водитель получает индивидуальные выплаты по утверждённым ставкам; пропуск проверки лишь предупреждает.
- Предварительные коммерческие цены из прежних файлов **не утверждены**.

## Ограничения

Это заготовка работающего продукта, не действующий рекламный маркетплейс. Перед запуском ещё нужны реальные заказы, система менеджеров, проверка прав, финансовые операции, отчётность, чат, законные согласия, безопасность и ежедневные резервные копии.
