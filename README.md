# RReklam

RReklam — платформа рекламной сети автомобилей по Армении. Основной продукт: размещение рекламы на частных автомобилях, такси и автопарках через менеджеров агентства.

## Статус

**Начальная разработка, не production.** Подробности: [состояние реализации](docs/IMPLEMENTATION_STATUS.md). Исходное мастер-ТЗ 2026-10-28 хранится у владельца проекта; его решения имеют приоритет над демонстрационными данными.

## Локальный запуск

Требуется Node.js 20+ и npm.

```bash
npm install
cp .env.example .env
npm run dev
```

Открыть http://localhost:3000 — маршруты /hy, /ru, /en. Публичная форма `/[lang]/request` пока делает только локальный предпросмотр. Она не принимает оплату и не создаёт заказ.

## База данных

Требуется локальный PostgreSQL. Указать DATABASE_URL в .env, затем:

```bash
npm run db:generate
npm run db:migrate
```

Для предотвращения двойного бронирования требуется **отдельная SQL-миграция** из `prisma/sql/booking_constraints.sql` (выполнить один раз после создания таблиц; лучше включить SQL в контролируемую Prisma migration). Без неё нельзя включать реальное бронирование автомобилей.

Проверка чистой бизнес-логики:

```bash
npm test
```

## Правила бизнеса

- Пользовательский язык: армянский по умолчанию; есть русский и английский.
- Заказ на несколько городов; отдельное количество машин для каждого.
- Реальную доступность машин **не раскрывать клиентам**.
- На автомобиль одновременно только одно несовместимое назначение.
- Маржинальность от цены после прямых затрат — минимум 25%; ниже — исключение только владельцем с обоснованием.
- Скидка и изменение базового тарифа требуют утверждения владельца.
- Водителю платят по индивидуальному графику; пропущенные фотопроверки только предупреждают.
- Оплата клиентом 100% заранее; выпуск платежей только владельцем.
- Фото автомобиля: 4 стороны; обязательная модерация; водитель может добавить много машин; автопарки ведёт менеджер.

Полные ограничения, права доступа, проверка фото и финансы ещё необходимо реализовать на защищённом сервере.
