# RReklam — состояние реализации
## Выполнено
- Начальная инфраструктура Next.js App Router, TypeScript, Tailwind.
- Публичный каркас на /hy /ru /en и разделы главной страницы.
- Локальный предпросмотр заявки: несколько городов, количество машин на каждый город, формат и 7/14/30/90 дней. **Не отправляет заявку на сервер**.
- Черновая Prisma-схема PostgreSQL для пользователей, автомобилей, городов, автопарков, кампаний, назначений, тарифов, водителей, проверок и аудита.
- SQL для запрета пересекающихся бронирований на уровне PostgreSQL; применять после первичной миграции.
- Чистые бизнес-функции и модульные тесты: маржинальность 25%, исключения владельца, пересечение дат, доступность.
## Не реализовано, нельзя считать работающим
- Авторизация, SMS, Google, серверные RBAC и права на отдельных записях.
- Реальная регистрация автомобилей, обработка файлов, модерация, API и сохранение заказов.
- Платежи, выплаты, бухгалтерия, фактический контроль approve-событий через защищённый серверный обработчик.
- Расписание ежедневных проверок, камера и OTP, чат, уведомления, отчёты и резервные копии.
- Реальные утверждённые тарифы. Известная Excel-модель содержит расчётные цены; публиковать её нельзя.
- Фактические интеграционные тесты PostgreSQL и проверка сборки в CI.
## Важно
Это **первый коммит разработки**, а не готовый продукт. Перед применением SQL-ограничений выполняйте их в контролируемой миграции и проверьте на тестовой базе. При ручном вводе затрат сумма не должна подтверждаться без полного заполнения обязательных категорий затрат. Страница /request сейчас только предпросмотр без контактов и оплаты.
